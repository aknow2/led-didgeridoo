
# UFO Light
機能概要
ESPNowでデータを受信して、受信した値に応じしてLEDライトやレーザーライトを射出する

# 利用するライブラお
#include <esp_now.h>
#include <WiFi.h>
#include "M5Atom.h"
#include <FastLED.h>



### T0 変数定義と初期化
PIN25番がLED
PIN32番がレーザーとする
ESP nowの初期化 とLED, レーザーをOFFする
これらはsetup関数で実装する

### T1 ボタンによるモード切り替え
共通
- ボタンが押されたらモードが切り替わる
- モード１は青
- モード２は赤
- モード３は緑

### T2 モード１
LED点灯モード
このモードでは受信したデータは関係なくLEDだけを点灯する

一度に点灯するのは3つのLEDだけで、1秒毎にLEDの位置がずれていく
具体的にはLEDの数は24個がリンク状につながっており、初期のLEDの位置は[0, 8, 16]とする。
1秒毎に位置が[1, 9, 17] -> [2, 10, 18]と変わっていく
表示する色はランダムで決定し、輝度はMAXとする

### T3 モード２
LED + レーザーモード
このモードでは受信したデータは関係なくLEDとレーザーが交互に光る

LEDが10秒間、レーザーが２秒間光る
LEDの光り方はモード１と同じである


### T4 モード3
モード３では、通常はLEDが光続ける。光り方はモード１と同じ
valueの値が２０を超えたら、モード２と同じような光り方になる
